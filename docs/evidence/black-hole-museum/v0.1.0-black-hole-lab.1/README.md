# Black Hole Museum Evidence Record

Release: `0.1.0-black-hole-lab.1`

This directory records automated verification and the external blockers encountered during implementation.

## Confirmed locally

- Friendly source and JSON Schema validation.
- Ten exhibit stations.
- Scoped CSS and responsive breakpoints.
- Exact route and mount contract.
- Detached renderer commit.
- Bootstrap singleton, route gate, fallback requirement, timeout, and failure preservation.
- Keyboard focus styles and conventional control semantics.
- Reduced-motion and reduced-data editions.
- Media classifications, captions, alt text, credits, and authoritative source URLs.
- JavaScript syntax.
- Immutable semantic release URLs.
- Readable Edublogs fallback and noscript state.

## External blockers

1. The connected GitHub integration returned HTTP 403 `Resource not accessible by integration` for branch and Git data writes.
2. The execution environment could not resolve external hosts, preventing acquisition of the approved NASA, ESO, and EHT media.

The offline build therefore includes clearly labeled local SVG stubs and is correctly marked `deploymentReady: false`. It must not be represented as the final deployed scientific-media release.
